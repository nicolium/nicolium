## micolium

micolium is a React Native port of Nicolium. It is meant to provide better, native-like experience on Android and iOS devices. It uses React Native Paper for UI, offering interface similar to Moshidon, with a goal of implementing broad support for platforms other than Mastodon. It's currently in very early stage.

In the future, I want the app to reuse code from Nicolium, extracating more into a new library. But I'm too lazy now lol
